== Description ==

**Даний плагін надсилає смс повідомлення на телефон адміністратора або клієнта про події на сайті, у тому числі відстеження замовлень у плагіні WooCommerce, контактні форми та інше через сервіс [sms-fly.ua](https://sms-fly.ua)**

**Можливості:**

Повідомлення на телефон по смс про події на сайті.

* Повідомлення про публікацію нового посту.
* Повідомлення про оновлення посту.
* Повідомлення про те, що користувач залогінився на сайт.
* Повідомлення про встановлення нового плагіна.
* Повідомлення про оновлення плагіна.
* Повідомлення про встановлення нової теми.
* Повідомлення про оновлення теми.

Повідомлення на телефон по смс про замовлення плагіна WooCommerce.
* Повідомлення про нове замовлення телефону адміністратора.
* Повідомлення про нове замовлення телефону клієнта.
* Повідомлення про зміну статусу замовлення телефону адміністратора.
* Повідомлення про зміну статусу замовлення на телефон клієнта.

Повідомлення про події для Contact Form 7.

== Installation ==

1. Завантажте папку "smsfly" у "/wp-content/plugins/" каталог.
2. Activate the plugin through the 'Plugins' menu in WordPress.
2. Активируйте плагин "SMS-Fly для Wordpress" через меню "Плагіни" в WordPress.
